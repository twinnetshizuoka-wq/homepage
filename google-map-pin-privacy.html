プライバシーポリシー

Google Maps ピン刺しアプリ

制定日：2026年9月23日

本アプリのホームページ： https://www.twin-net.net/google-map-pin.html

本プライバシーポリシー： https://www.twin-net.net/google-map-pin-privacy.html

twin net（以下「当方」といいます。）は、当方が提供する「Google Maps ピン刺しアプリ」（以下「本サービス」といいます。）における、利用者の個人情報および利用者が登録する情報の取扱いについて、以下のとおり定めます。

1. 取得する情報

本サービスでは、以下の情報を取得・利用する場合があります。

1-1. Googleアカウントに関する情報

本サービスでは、データの保存・同期機能を利用するため、利用者がGoogleアカウントによるログインを選択した場合、Googleの認証機能を利用します。

この際、Googleから提供される認証情報のうち、本サービスの機能に必要な情報のみを利用します。

当方が利用者のGoogleアカウントのパスワードを取得・保存することはありません。

1-2. 利用者が登録する情報

本サービスでは、利用者が入力・登録した以下の情報を取り扱う場合があります。

  • 住所
  • 施設名、物件名、顧客名などの名称
  • 担当者情報
  • 営業状況、進捗状況
  • ピンの色やカテゴリ
  • 訪問予定などの管理情報
  • 備考、メモ等
  • その他、利用者が本サービスに入力した情報

これらの情報には、利用者自身の判断により個人情報が含まれる可能性があります。

本サービスでは、利用者が登録した情報を営業先、訪問先、物件、店舗、施設等の位置情報を管理する目的で利用します。

2. Googleサービスとの連携

本サービスでは、GoogleのサービスおよびGoogle APIを利用して、利用者が登録した地図データ等を利用者自身のGoogleアカウントと連携・同期できる機能を提供しています。

Googleアカウントとの連携を利用する場合、利用者の同意に基づき、Google APIを通じて必要なデータにアクセスします。

当方は、本サービスの機能提供に必要な範囲を超えてGoogleユーザーデータを取得、利用、保存または共有しません。

また、当方が利用者のGoogleアカウントのパスワードを取得または保存することはありません。

Google APIを通じて取得したユーザーデータについては、Google API Services User Data Policyおよび適用されるGoogleのポリシーに従って取り扱います。

Google APIを利用するアプリケーションでは、必要最小限の権限のみを要求することが推奨されています。

3. Googleユーザーデータの利用目的

Google APIを通じて取得した情報は、以下の目的に限って利用します。

  • 本サービスへのログインおよび利用者の認証
  • 利用者が登録した地図データ等の保存・同期
  • パソコン、スマートフォン等の複数端末間でのデータ利用
  • 本サービスの機能提供および維持

Googleユーザーデータを、広告目的で利用したり、利用者の許可なく第三者へ販売したりすることはありません。

また、Googleユーザーデータを本サービスの目的と関係のない用途に利用することはありません。

4. Googleユーザーデータの第三者提供

当方は、法令に基づく場合を除き、Google APIを通じて取得した利用者の情報を第三者に販売または提供しません。

ただし、本サービスの提供に必要なGoogleのサービスや、利用者が明示的に利用を選択した外部サービスについては、それぞれのサービスの利用規約およびプライバシーポリシーが適用されます。

Googleのユーザーデータについては、Google API Services User Data Policyの規定に従って取り扱います。

5. Google Mapsの利用

本サービスでは、地図の表示および位置情報の表示等のためにGoogle Maps Platformを利用しています。

Google Maps Platformの利用にあたっては、Googleの利用規約およびプライバシーポリシーが適用されます。

Google Maps Platformを利用するサービスでは、適切なプライバシーポリシーを公開することがGoogleの規約上求められています。

Google プライバシーポリシー：
https://policies.google.com/privacy

6. 広告について

本サービスでは、サービスの運営および維持を目的として、第三者が提供する広告配信サービスを利用する場合があります。

広告配信事業者は、広告配信や効果測定のためにCookie等を使用する場合があります。

利用する広告サービスについては、各広告配信事業者のプライバシーポリシーをご確認ください。

なお、Googleユーザーデータを広告配信のために利用することはありません。

7. Cookie等について

本サービスでは、サービスの提供、利用状況の確認、設定の保存、広告配信等のためにCookieまたはこれに類する技術を使用する場合があります。

Cookieは、利用者のブラウザに保存される情報であり、通常、個人を直接特定するものではありません。

利用者は、ブラウザの設定によりCookieの使用を制限または無効にすることができます。ただし、その場合、本サービスの一部の機能が正常に利用できなくなる場合があります。

8. アクセス解析について

本サービスでは、サービスの改善や利用状況の把握を目的として、アクセス解析サービスを利用する場合があります。

アクセス解析サービスでは、Cookie等を利用して利用状況に関する情報を収集する場合があります。

取得した情報は、サービスの改善、機能の追加・変更、不具合の確認等に利用します。

9. 利用者情報の管理

当方は、利用者から取得した情報について、適切な安全管理措置を講じ、不正アクセス、紛失、漏えい、改ざん等の防止に努めます。

また、利用者のGoogleアカウントの認証情報（パスワード等）を当方が取得・保存することはありません。

10. 利用者によるデータの管理

本サービスに登録した情報については、利用者自身の責任において適切に管理してください。

特に、顧客情報、個人情報、営業上の機密情報などを登録する場合は、利用者自身の責任において、登録する情報の内容および利用方法を判断してください。

Googleアカウントとの連携を解除した場合、本サービスのGoogleアカウントを利用した同期機能等が利用できなくなる場合があります。

11. 個人情報の開示・訂正・削除

利用者本人から、自身の個人情報について開示、訂正、削除等の申し出があった場合、本人確認を行ったうえで、法令に従い適切に対応します。

ただし、本サービスを通じて利用者自身が登録・管理している情報については、サービス上の機能または利用者自身のGoogleアカウント等から削除・変更できる場合があります。

12. 外部サービスについて

本サービスでは、Google Maps、Googleアカウント、Google Drive等のGoogleが提供するサービスを利用する場合があります。

これらの外部サービスについては、それぞれのサービス提供者が定める利用規約およびプライバシーポリシーが適用されます。

Googleのプライバシーポリシー：
https://policies.google.com/privacy

13. プライバシーポリシーの変更

当方は、必要に応じて本プライバシーポリシーを変更することがあります。

重要な変更がある場合には、本サービス上で告知するなど、適切な方法で利用者にお知らせします。

変更後のプライバシーポリシーは、本ページに掲載した時点から適用されます。
